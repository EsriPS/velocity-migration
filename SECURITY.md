# Security Policy

This repository collects community feedback for the **ArcGIS Velocity Migration Tool**.
It does not contain the application's source code.

## Reporting a security vulnerability

**Do not report security vulnerabilities through public GitHub issues or discussions.**

Security vulnerabilities in ArcGIS software, including the ArcGIS Velocity
Migration Tool, are handled by the **Esri Product Security Incident Response Team
(PSIRT)**. Please report them through the Esri Trust Center:

- **[Report a Security or Privacy Concern](https://trust.arcgis.com/en/security-concern/)**

When submitting, choose the **ArcGIS Software Vulnerability** category and include
sufficient detail to reproduce and assess the issue, such as a description of the
impact, steps to reproduce or a proof of concept, and the affected versions or
components. Esri PSIRT provides a
[public PGP key](https://trust.arcgis.com/en/security-concern/esri-psirt-pgp.asc)
for encrypting sensitive details when communicating with the team.

Esri is a [CVE Numbering Authority (CNA)](https://www.cve.org/PartnerInformation/ListofPartners)
and assigns CVE identifiers following coordinated vulnerability disclosure
guidelines. Esri PSIRT commits to acknowledge receipt of your report, provide an
estimated time frame for addressing it, and notify you when it has been resolved.

## Responsible disclosure

Esri encourages responsible reporting and will not pursue legal action against
researchers who follow the Trust Center
[Vulnerability Reporting Policy](https://trust.arcgis.com/en/security-concern/).
In particular, the policy does **not** permit:

- Causing, or attempting to cause, a Denial of Service (DoS) condition.
- Using automated security tools without Esri's explicit consent.
- Accessing, or attempting to access, data that does not belong to you.
- Destroying or corrupting data that does not belong to you.

If you are requesting validation of an automated vulnerability scan, review Esri's
[Automated Scanning Guidance and requirements](https://downloads.esri.com/resources/enterprisegis/esri_vulnerability_reporting_and_disclosure_program.pdf)
before submitting.

## Product help and private details

For non-security questions or to share configuration details privately during
troubleshooting, [open an Esri support case](https://support.esri.com/en-us/contact/create-case)
rather than posting in this repository.

## Handling of sensitive data

This is a public space. Never post GeoEvent Server configuration exports,
credentials, hostnames, or other sensitive information in issues or discussions.
See the [README](README.md#protecting-sensitive-data) for details.
